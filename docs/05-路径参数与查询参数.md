## 5.1 路径参数（Path Parameter）

下面的路由片段假定已导入 `net/http`、`fmt` 和 `github.com/gin-gonic/gin`，并在已初始化的 `r` 或 `api` 上注册。

路径参数是 URL 路径中的动态部分：

```
/users/123      → id = 123
/users/abc      → id = abc
/articles/hello-world  → slug = hello-world
```

### 基础用法：`:param`

```go
// :id 匹配单个路径段
r.GET("/users/:id", func(c *gin.Context) {
	id := c.Param("id")  // 获取路径参数
	c.JSON(http.StatusOK, gin.H{
		"message": fmt.Sprintf("查询用户 %s", id),
	})
})
```

```bash
curl http://localhost:8080/users/123
# {"message":"查询用户 123"}

curl http://localhost:8080/users/abc
# {"message":"查询用户 abc"}
```

### 多个路径参数

```go
// :owner 和 :repo 是独立的参数
api.GET("/repos/:owner/:repo", func(c *gin.Context) {
	owner := c.Param("owner")
	repo := c.Param("repo")
	c.JSON(http.StatusOK, gin.H{
		"owner": owner,
		"repo":  repo,
	})
})
```

```bash
curl http://localhost:8080/api/repos/gin-gonic/gin
# {"owner":"gin-gonic","repo":"gin"}
```

### 通配符 `*param`：匹配剩余全部路径

```go
// *filepath 匹配 /static/ 后面的所有内容；参数值通常包含前导斜杠
r.GET("/static/*filepath", func(c *gin.Context) {
	filepath := c.Param("filepath") // 例如 "/css/style.css"
	c.String(http.StatusOK, "请求的文件：%s", filepath)
})
```

```bash
curl http://localhost:8080/static/css/style.css
# 请求的文件：/css/style.css

curl http://localhost:8080/static/js/app.js
# 请求的文件：/js/app.js
```

## 5.2 查询参数（Query Parameter）

下面的片段继续使用前面已初始化的 Gin 引擎；完整搜索示例会在 5.5 节给出。

查询参数是 URL 中 `?` 后面的 `key=value` 对：

```
/users?name=张三&age=25&city=北京
       └──┬──┘ └─┬─┘ └──┬──┘
        name    age    city
```

### 获取查询参数

> 下面的 `/users` 路由是独立示例。继续学习数组参数一节时，请将它替换为下一节的版本，不能在同一个 Gin 引擎上重复注册同一方法和路径。

```go
r.GET("/users", func(c *gin.Context) {
	// 直接获取（不存在时返回空字符串）
	name := c.Query("name")

	// 带默认值（不存在时返回默认值）
	age := c.DefaultQuery("age", "18")

	// 获取并判断是否存在
	city, exists := c.GetQuery("city")
	if !exists {
		city = "未知"
	}

	c.JSON(http.StatusOK, gin.H{
		"name": name,
		"age":  age,
		"city": city,
	})
})
```

```bash
# 传入所有参数
curl "http://localhost:8080/users?name=张三&age=25&city=北京"
# {"age":"25","city":"北京","name":"张三"}

# 不传 age 和 city
curl "http://localhost:8080/users?name=张三"
# {"age":"18","city":"未知","name":"张三"}
```

### 获取多个同名参数（数组）

> 下面的 `/users` 路由与上一节同名，是替代示例；请只保留一个注册，不能在同一个 Gin 引擎上重复注册同一方法和路径。

```go
r.GET("/users", func(c *gin.Context) {
	// 获取所有同名的 ids 参数；返回值仍然是字符串切片
	ids := c.QueryArray("ids")
	// QueryMap("filter") 读取 filter[name]=张三 这样的嵌套参数
	queryMap := c.QueryMap("filter")

	c.JSON(http.StatusOK, gin.H{
		"ids":    ids,
		"filter": queryMap,
	})
})
```

```bash
curl --globoff "http://localhost:8080/users?ids=1&ids=2&ids=3&filter[name]=张三"
# {"filter":{"name":"张三"},"ids":["1","2","3"]}
```

## 5.3 路径参数 vs 查询参数：怎么选

| 路径参数 `/users/:id` | 查询参数 `?name=张三` |
|---------------------|---------------------|
| 常用于**标识资源或层级** | 常用于**过滤/排序/搜索/分页** |
| 对匹配该路由而言，路径段必须存在 | 通常可选，也可由接口定义为必填 |
| 表示“哪个资源” | 表示“用什么条件查询” |

```
✅ 好的设计：
GET /users/1                ← 路径参数：标识"1号用户"这个资源
GET /users?status=active    ← 查询参数：筛选活跃用户
GET /users?page=2&page_size=10  ← 查询参数：分页

❌ 不好的设计：
GET /users?id=1             ← 路径参数更适合标识资源
GET /users/active           ← /active 是状态不是资源
```

## 5.4 获取所有查询参数

```go
r.GET("/debug", func(c *gin.Context) {
	// 获取原始查询字符串
	rawQuery := c.Request.URL.RawQuery
	fmt.Println("原始查询:", rawQuery)

	// 获取解析后的 map
	queryMap := c.Request.URL.Query()
	for key, values := range queryMap {
		fmt.Printf("%s = %v\n", key, values)
	}

	c.JSON(http.StatusOK, gin.H{"query": rawQuery})
})
```

## 5.5 完整实战：搜索接口

```go
package main

import (
	"fmt"
	"net/http"
	"strconv"

	"github.com/gin-gonic/gin"
)

func main() {
	r := gin.Default()

	// GET /api/v1/users?keyword=张&status=active&page=1&page_size=10
	r.GET("/api/v1/users", func(c *gin.Context) {
		keyword := c.DefaultQuery("keyword", "")
		status := c.DefaultQuery("status", "all")
		page, err := strconv.Atoi(c.DefaultQuery("page", "1"))
		if err != nil || page < 1 {
			c.JSON(http.StatusBadRequest, gin.H{"error": "page 必须是大于等于 1 的整数"})
			return
		}
		pageSize, err := strconv.Atoi(c.DefaultQuery("page_size", "10"))
		if err != nil || pageSize < 1 || pageSize > 100 {
			c.JSON(http.StatusBadRequest, gin.H{"error": "page_size 必须是 1 到 100 之间的整数"})
			return
		}

		c.JSON(http.StatusOK, gin.H{
			"keyword":   keyword,
			"status":    status,
			"page":      page,
			"page_size": pageSize,
			"message":   fmt.Sprintf("搜索关键词=%s, 状态=%s, 第%d页, 每页%d条", keyword, status, page, pageSize),
		})
	})

	if err := r.Run(":8080"); err != nil {
		panic(err)
	}
}
```

```bash
curl "http://localhost:8080/api/v1/users?keyword=张&status=active&page=1&page_size=10"
# {"keyword":"张","message":"搜索关键词=张, 状态=active, 第1页, 每页10条","page":1,"page_size":10,"status":"active"}
```

## 常见错误

### 错误1：混淆 `:` 和 `*`

```go
// :id 只匹配一个路径段（不含 /）
r.GET("/files/:filename")  // /files/abc.txt ✅   /files/a/b.txt ❌

// *filepath 匹配所有剩余路径（含 /）
r.GET("/files/*filepath")  // /files/a/b.txt ✅
```

### 错误2：Query 参数类型转换时忽略错误

```go
// ❌ c.Query 返回的是 string；忽略转换错误会把非法输入当成有效值
age, _ := strconv.Atoi(c.DefaultQuery("age", "0"))

// ✅ 转换并校验
age, err := strconv.Atoi(c.DefaultQuery("age", "0"))
if err != nil || age < 0 {
	c.JSON(http.StatusBadRequest, gin.H{"error": "age 必须是非负整数"})
	return
}
```

### 错误3：拼接查询字符串时没有编码

```bash
# curl 通常可以处理命令行中的 UTF-8 URL，但直接拼接任意用户输入并不安全
curl --get --data-urlencode "name=张三" http://localhost:8080/users
```

Go 代码中先导入 `net/url`，再使用 `url.Values` 构造查询字符串，避免手工拼接：

```go
values := url.Values{}
values.Set("name", "张三")
requestURL := "/users?" + values.Encode()
```

## 本章小结

- `:param` 匹配单段路径，`*param` 匹配剩余全部路径
- `c.Param("id")` 获取路径参数
- `c.Query("key")` / `c.DefaultQuery("key", "default")` 获取查询参数
- `c.QueryArray("ids")` 获取数组参数
- 路径参数常用于定位**资源或层级**，查询参数常用于表达**筛选条件**
- Query 参数都是 string，需要手动类型转换
